═══════════════════════════════════════════════════════════════════════════════

2. NAVEGA A LA CARPETA:

3. INSTALA DEPENDENCIAS:
   npm install

4. INICIA LA APLICACIÓN:
   npm run dev

5. ABRE EN NAVEGADOR:
   http://localhost:5173

                         SOPORTE RÁPIDO
═══════════════════════════════════════════════════════════════════════════════

❌ "Module not found"
   → Ejecuta: rm -r node_modules && npm install

❌ "Port already in use"
   → Cambia el puerto en vite.config.ts

❌ "npm no encontrado"
   → Instala Node.js desde nodejs.org

❌ "Datos no se guardan"
   → Verifica que localStorage esté habilitado en el navegador

✓ Para más ayuda → Lee los archivos README.md
